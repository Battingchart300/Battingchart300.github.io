About Me

16-year-old student from Slovakia building with Python, Docker and local AI. Working on my own assistant (JARVIS) and small tools that run locally.

My Story

I started building because I wanted tools that actually work for me — a file converter that needs no upload, a data cleaner that runs in one command, a Docker setup that just works. Everything I build is open source, so anyone can read the code and run it.

My Mission

To build practical, local-first tools that solve real problems — no cloud, no account, no tracking.

My Vision

To grow PTS — Pathos Company Corporation — into my own technology company: software, AI, automation and infrastructure.
